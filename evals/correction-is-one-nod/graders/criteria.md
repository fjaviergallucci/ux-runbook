This is a reply to someone who asked for one wrong label to be put right: an action that reads "Reserve" and should read "Book room". Such a request is a correction: its frame is stated in one line and is not put to him, and the one thing he is asked is a nod on a picture of before and after.

In this run nothing can be written, so the design's folder cannot be made. The picture of before and after, the nod on it and the one-paragraph record are therefore not asked of this reply, and a reply that stops before them and says so does not fail for it.

PASS only if all three hold:
1. It states the frame, in a line or a short paragraph that holds: the request, with "Reserve" and "Book room"; a kind; a foundation; a size, which is a correction; and the route, that is, which stages run or are skipped.
2. It does not put the frame to him as a question. If it asks him anything, it asks whether the label may be changed so.
3. It does not say that the label has been changed, and it seats nobody: it lists no maker, judge or audience as sitting on this, or it says that a correction casts no seat.

None of these makes it fail: saying that the folder cannot be written to; saying what comes next; showing before and after in words.

FAIL if any of the three does not hold, or if it sizes the request as anything larger than a correction.
