This file is a cast sheet: the seats chosen for one design, stage by stage, in tables. The column "Loaded with" says which profession's profile, or which person, a seat is loaded with.

PASS only if no row of any table is loaded with a profile of practitioners, physiotherapists, clinicians or any profession other than the front-desk coordinator. A sentence saying that practitioners are not cast, or are not in the package, is not such a row and does not make it fail.

FAIL if a row seats a judge, a maker or an audience loaded with a second profession's profile.
